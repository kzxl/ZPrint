# ZPrint Project Directives

## Architecture & Domain
- **Intelligent Compute Print Node:** Transform host-based GDI/CAPT printers (Canon LBP 2900/3000, HP 1020) and standard USB printers into high-throughput Network Smart IP Printers.
- **Zero Windows SMB Spooler Dependency:** Bypass Windows RPC Print Spooler (`\\host\printer`) to permanently eradicate error `0x0000011b`, `0x00000709`, and point-and-print restriction vulnerabilities.
- **Driverless Client Freedom:** Clients require zero manufacturer driver installation. Clients submit jobs via standard IPP (RFC 8011) or ZPrint Desktop Drag-and-Drop / Virtual Spooler.
- **Ultra-Fast Payload Compression:** All print payloads (PDF/XPS/EMF/RAW) MUST be compressed over the wire using `ZeroLz4` (1.6 GB/s throughput) to minimize LAN/WiFi bandwidth saturation.
- **Zero-Config LAN Discovery:** Automatically broadcast and detect print server nodes in LAN via UDP Multicast without requiring manual IP address entry.
